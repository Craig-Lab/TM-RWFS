
**Trajectory Matching-Random Walk Feasibility Sampling Algorithm**

**Overview**

TM-RWFS is a computational algorithm for simulating heterogeneous dynamics in mechanistic mathematical models.

The repository provides data corresponding to all the models investigated in the study. The Lotka-Volterra model is used as an example to demonstrate the implementation of the TM-RWFS algorithm. 

**Requirements**

•	Julia ≥ 1.10

•	Installation guide: https://julialang.org/install/

**Inputs**

•	Experimental or clinical data

•	Mathematical model (ODEs, DDEs), parameters best fit values

•	TM-RWFS parameters

**Outputs**

•	Accepted trajectories

•	Parameters distributions

•	Execution time

**Code Availability**
